# The process journal

How gnoworld gets built, kept for the record. The decisions that shape the product are in [../KEY-DECISIONS.md](../KEY-DECISIONS.md);
what follows is the working journal behind them, written for the people building gnoworld and the agents helping them. Git's
history keeps every earlier version.

| File | What it holds |
|---|---|
| [decisions.md](decisions.md) | Every day-to-day decision, one row each with its reason and where it lives (ids `D…`), newest last |
| [review/findings.md](review/findings.md) | Every finding a review raised and what became of it (ids `F…`); `review/` also holds the review exercises |
| [review-log.md](review-log.md) | Each branch's review rounds: what was caught, what was missed, and why |
| [plans/](plans/backlog.md) | Each slice's plan, and the backlog, the order of work |
| [design/](design/video-screens.md) | Design notes: the prototype's screens, coherence, textures, the 3D |
| [claude-code.md](claude-code.md) | Working with Claude Code: sessions, worktrees, `land`, the ping-pong |
